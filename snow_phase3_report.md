# Фаза 3: вставка по клику и авто-клин подложки

Дата: 2026-11-05. Ветка: `community/gpu-screentone-preview`.

## Что сделано

- `paste_on_click` (уже был в `TypesetterOptions` и в Settings) доведён до рабочего цикла:
  при включённом флаге новое выделение (Magic Wand / лассо) вставляет текущую реплику и
  **сдвигает очередь на следующую строку** (`advance_line` + `auto_save`). Раньше вставка была,
  сдвига не было.
- Новый модуль `crates/ui-egui/src/snow_clean.rs` (префикс `snow_`):
  - `clean_fill_color(layer, selection)` — средняя яркость выбранной области под слоем: светлая
    графика → белая заливка, тёмная → чёрная (порог 118);
  - `mean_luminance` — выборка с ограничением 4096 проб (шаг считается по площади), прозрачные
    пиксели выделения пропускаются;
  - `color_for_luminance`, `sample_step`, `is_sampleable`, `CLEAN_LAYER = "TypeR Clean"`.
- `PhotocraftApp::typesetter_clean_selection()` — перед вставкой заливает выделение чистым цветом
  на слое `TypeR Clean` (слой создаётся при первом клине и переиспользуется), через команды
  `layer.new.layer` / `layer.select` / `edit.fill`.
- Paste-on-click и мульти-бабл вставка вызывают авто-клин, если включён `auto_clean`
  (`edit.fill` учитывает активное выделение, поэтому заливается ровно баллон).
- В футер TypeR добавлены два чекбокса: **«Вставка по клику»** и **«Авто-клин»** (сохраняются в
  `typesetter_state.json`, дублируют настройки во вкладке Options).

## Тесты

```
cargo test -p photocraft-ui-egui --lib snow_clean       # 3 passed
cargo test -p photocraft-ui-egui --lib snow_paste       # 3 passed
cargo test -p photocraft-ui-egui --lib snow_typesetter  # 16 passed
```

Покрыто: порог белого/чёрного, бюджет выборки, CMYK не сэмплируется (белый клин), светлый баллон
заливается белым и очередь сдвигается, тёмный — чёрным, без флага слой `TypeR Clean` не создаётся.

## Ручная проверка в GUI

1. В футере TypeR включить «Вставка по клику» и «Авто-клин».
2. Взять Magic Wand, кликнуть внутрь баллона с исходным текстом.
3. Ожидаемо: баллон заливается чистым белым/чёрным на слое `TypeR Clean`, поверх появляется
   отцентрированный перевод (Point Text), активная строка сценария становится следующей.
4. Слой `TypeR Clean` виден в палитре слоёв и редактируется отдельно.

## Ограничения

- Цвет клина выбирается по яркости активного пиксельного слоя; для векторных/текстовых слоёв под
  выделением клин белый.
- Рабочее дерево содержит незакоммиченную работу другого агента (text shape, auto-align,
  multi-bubble), поэтому интеграция (lib.rs / snow_typesetter_ui.rs / engine options) лежит поверх
  неё; в Git добавлены новые файлы `snow_clean.rs`, `snow_paste_tests.rs` и этот отчёт.
