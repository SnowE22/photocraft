# Как протестировать правки (29 октября 2026)

Пошаговый прогон всех изменений последней сессии: TypeR UI (записи 18–22 в
`snow_changelog_today.md`) и новый инструмент баблов (запись 23).

- Приложение: `D:\Photoncraft\release\photocraft.exe`
- CLI: `D:\Photoncraft\release\release\photocraft-cli.exe`
- Демо-картинка с баблами: `D:\Photoncraft\release\balloon-demo.png`
- Копия этого гайда и changelog лежат рядом с exe.

---

## 0. Подготовка (1 минута)

1. Закройте запущенный PhotoCraft, если он открыт: при обновлении exe файл занят и не
   перезапишется.
2. Убедитесь, что exe свежий: правый клик по `photocraft.exe` → Свойства → «Дата изменения»
   должна быть 29.10.2026 (или позже даты вашей сборки).
3. Сделайте копию своего `typesetter_state.json`, если жалко накопленные стили TypeR:
   `%APPDATA%\photocraft\typesetter_state.json` (Windows). Гайд меняет только UI и стили
   читает, но на всякий случай.
4. Для проверки на другом масштабе: Параметры Windows → Дисплей → «Масштаб» 100 % / 125 %.

## 1. Единый редактор сценария TypeR (запись 18)

Откройте TypeR (Window → TypeR / панель TypeR), вкладка «Сценарий» с загруженным скриптом.

- [ ] **Сквозное выделение:** зажмите ЛКМ в середине строки 1 и протяните через строки 2–3 —
      выделяется один непрерывный синий блок; `Ctrl+C` / `Ctrl+V` / `Delete` работают как в
      обычном текстовом поле.
- [ ] **Backspace в начале строки:** поставьте курсор в начало 2-й строки, нажмите `Backspace` —
      строки 1 и 2 склеиваются, нумерация ниже пересчитывается.
- [ ] **Enter в середине фразы:** курсор в середину длинной реплики, `Enter` — реплика делится
      на две строки с новыми номерами.
- [ ] **Word wrap:** вставьте очень длинную строку — она переносится внутри своего номера, а не
      обрезается справа.
- [ ] **Гуттеры:** слева номера (моноширинный шрифт) и иконки статуса (`◎` / `●`), справа кнопка
      отправки строки на холст.
- [ ] **Сплиттер:** потяните нижнюю границу сценария — высота редактора меняется (80…600 px),
      количество видимых строк соответствует новому размеру.
- [ ] **Сохранение высоты:** закройте и откройте PhotoCraft — высота сценария та же.

Ожидаемый результат: ни одно действие не «съедает» текст и не ломает нумерацию.

## 2. Пропорциональный текст и имена стилей своим шрифтом (запись 19)

- [ ] Текст сценария — пропорциональным шрифтом (не моноширинным); номера строк и гуттеры
      остались моноширинными.
- [ ] В списке стилей («Манга», «Диалоги» и т.п.) названия нарисованы **шрифтом стиля**: сравните
      «Дедот» (рукописный) и «КРИК» (узкий) — начертания разные.
- [ ] Стиль с отсутствующим шрифтом показывает обычную подпись с обрезкой (без пустой плашки и
      без наезда на кнопку ✏).

## 3. Чёткие имена стилей и интерлиньяж сценария (запись 20)

Главная проверка — **на масштабе Windows 125 % или 150 %** (или `Настройки → Интерфейс →
масштаб UI`, если у вас так задано).

- [ ] Имена стилей в карточках резкие, без «мыльного» ореола; край букв такой же чёткий, как у
      соседних подписей UI («Звуки (1)», «Манга (18)»).
- [ ] Строки сценария разделены заметным интервалом; пунктирные линии-разделители не режут текст.
- [ ] Спойлер-проверка: на масштабе 100 % разницы «до/после» почти нет — это нормально.

## 4. Перетаскиваемые окна (запись 21)

- [ ] В TypeR нажмите ✏ у любого стиля → открывается «Настройки шрифта: …».
- [ ] Потяните окно за заголовок вверх, вниз, влево — окно следует за курсором (раньше висело
      по центру).
- [ ] Закройте и откройте настройки **другого** стиля — окно открывается там, куда вы его
      перетащили.
- [ ] То же для окна «Редактор сценария» (кнопка «Редактор» в панели сценария) и окна
      «Manga Script (Full Text)».

---

## 5. Придоканная панель открывает окна (запись 22)

- [ ] Перетащите вкладку TypeR в левый или нижний док (или закрепите панель доком).
- [ ] В придоканной панели нажмите ✏ у стиля — окно настроек открывается и перетаскивается.
- [ ] Нажмите «Редактор» — открывается окно редактора сценария.
- [ ] Верните панель в плавающий режим — окна по-прежнему открываются и **не дублируются**
      (не появляются две копии друг на друге).

## 6. Инструмент баблов: хвосты, облака, шипы, SAI-штрихи (запись 23)

> **Важно:** пока это engine-команды. В GUI инструмент ещё не подключён (следующий шаг),
> поэтому тестируем через CLI — он уже собран с этими командами.

Откройте PowerShell и перейдите в папку релиза:

```powershell
cd D:\Photoncraft\release
$cli = ".\release\photocraft-cli.exe"
```

### 6.1. Хвост + бабл, один контур (Этап 1)

```powershell
& $cli run --new '{"width":700,"height":500,"background":"white","depth":8}' `
  --cmd shape.create --params '{"kind":"ellipse","rect":[120,60,320,240],"fill":"#ffffff","stroke":{"width":5,"color":"#111111"}}' `
  --cmd shape.balloon.tail --params '{"preset":"arc","tip":[300,450],"mouthWidth":46,"curve":0.5}' `
  --out tail-arc.png
```

Ожидаемо: овал с аккуратным хвостом вниз; на стыке устья **нет поперечной линии**, обводка одна.
Откройте `tail-arc.png`.

- [ ] Варианты пресетов: `"preset":"wedge"` (прямой клин), `"arc"` (изогнутые бока), `"double"`
      (два хвоста), `"thought"` (пузырьки; хвост — отдельные круги, это норма).
- [ ] Вариант «протяжкой из точки»: вместо `base` указать `"from":[260,300]` — устье на этой
      точке, хвост к `tip`.
- [ ] Проверка «без шва»: увеличьте PNG (200–400 %), линия на стыке должна быть непрерывной.

### 6.2. Облако мыслей и шипастый бабл (Этап 2)

```powershell
& $cli run --new '{"width":800,"height":400,"background":"white","depth":8}' `
  --cmd shape.balloon.create --params '{"kind":"cloud","rect":[40,40,320,200],"bumps":11,"amplitude":0.22,"jitter":0.4,"seed":3,"stroke":{"width":4,"color":"#111111"}}' `
  --cmd shape.balloon.create --params '{"kind":"spiky","rect":[420,40,340,200],"spikes":16,"length":0.55,"jitter":0.4,"smooth":true,"stroke":{"width":4,"color":"#111111"}}' `
  --out clouds.png
```

Ожидаемо: слева «пушистое» облако с разным размером дуг, справа — «морской ёж».
Параметры для экспериментов:

- `bumps` 3…64 — количество дуг облака; `amplitude` 0…1 — высота дуг; `jitter` 0…1 — разброс
  размеров; `seed` — другой рисунок при тех же числах.
- `spikes` 3…128 — число игл; `length` 0…2 — длина; `jitter` — разброс; `inward:true` — иглы
  внутрь (эффект «взрыв внутрь»); `smooth:true` — скруглённые лучи.

### 6.3. SAI-вектор кликами (Этап 3)

```powershell
& $cli run --new '{"width":600,"height":300,"background":"white","depth":8}' `
  --cmd shape.balloon.stroke --params '{"points":[{"x":40,"y":220,"pressure":0.0},{"x":180,"y":80,"pressure":1.0},{"x":330,"y":150,"pressure":0.6},{"x":560,"y":60,"pressure":0.0}],"width":14,"minRatio":0.05}' `
  --out sai-line.png
```

Ожидаемо: плавная линия, которая плавно начинается/заканчивается «острым» кончиком (давление 0 на
концах) и толще в середине.

```powershell
# равномерная обводка (не заливка), с острым узлом:
& $cli run --new '{"width":600,"height":300,"background":"white","depth":8}' `
  --cmd shape.balloon.stroke --params '{"points":[[40,220],[180,80,true],[560,60]],"width":6,"tapered":false}' `
  --out sai-uniform.png
```

- [ ] `tapered:true` → слой с заливкой (filled outline), `tapered:false` → слой только с обводкой.
- [ ] Третий элемент `[x,y,true]` в точке делает её острым углом (в tapered-режиме не влияет).

### 6.4. Совместимость и Undo/Redo

- [ ] После любой из команд слой остаётся **shape-слоем**: он двигается Move-инструментом,
      масштабируется Free Transform (`Ctrl+T`), в панели Properties видны заливка/обводка.
- [ ] `Ctrl+Z` отменяет операцию целиком (одним шагом), `Ctrl+Shift+Z` возвращает.
- [ ] Сохраните документ в `.psd`, откройте его снова (или в Photoshop) — бабл на месте, как
      обычный векторный контур.

## 7. Автоматические проверки (для разработчика)

Все команды — из каталога `D:\Photoncraft\photocraft`, target-каталог уже настроен.

```powershell
$env:CARGO_TARGET_DIR='D:\Photoncraft\release'

# Геометрия баблов (union, облако, шипы, SAI, tapered)
cargo test -p photocraft-vector --lib balloon

# Команды shape.balloon.*
cargo test -p photocraft-engine --lib balloon_cmds

# UI TypeR: окна, придоканные диалоги, синхронизация сценария
cargo test -p photocraft-ui-egui --lib snow_typesetter

# Чёткие имена стилей на масштабах 1.0/1.25/1.5/2.0
cargo test -p photocraft-ui-egui --lib font_preview

# Ни одна команда не падает на враждебных параметрах
cargo test -p photocraft-engine --test panic_hunt -- --ignored
```

Ожидание: `test result: ok` во всех пяти запусках (9, 7, 4, 10 и 1 тест соответственно).
