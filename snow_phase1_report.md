# Фаза 1: детектор языка и мультиязычные переносы

Дата: 2026-11-05. Ветка: `community/gpu-screentone-preview`.

## Что сделано

- Новый модуль `crates/engine/src/snow_hyphenation.rs` (префикс `snow_`, как требует форк):
  - `LANGUAGES` — de/en/es/fr/it/pt/ru/tr/uk (порядок TypeR).
  - `detect_language` — определение языка по частотным словарям TypeR (7 языков, перенесены
    дословно из `hyphenation.js`) и сигнатурным буквам с весом 1.5; строгое преимущество,
    иначе `None`.
  - `resolve_language` — правила `resolve` из JS: неразрывные письменности (арабский, тайский,
    кана/иероглифы, хангыль) → `None`; кириллица → `uk` при і/ї/є/ґ, иначе `ru`; без латиницы →
    `None`; латиница → детектор или `en`.
  - `hyphen_break_points(word, lang)` — точки разрыва как индексы СИМВОЛОВ:
    - ru/uk — слоговой алгоритм по гласным (одиночная согласная отходит к следующему слогу,
      допустимые onset-кластеры идут вместе);
    - fr — перенос penalty-функции TypeR (гласная-гласная 7, согласная-гласная 16, x между
      гласными 12, onset 7, coda≥2 10, «e/es» 6, h 6; берутся penalty < 3);
    - en/de/es/it/pt/tr — общая эвристика «после гласной группы перед согласной», минимум 2
      буквы слева/справа, для de сохраняются кластеры st/sp/ck/ss/tz/pf/sch, для en не режутся
      суффиксы ing/ed/es;
    - апостроф внутри слова режется только во французском и итальянском.
  - `byte_break_points`, `hyphenate` — байтовые смещения и выбор языка.
- `snow_knuth_plass.rs`: `hyphenation_candidates` теперь берёт точки из `snow_hyphenation`
  (язык определяется по слову/тексту), старый эвристический fallback сохранён для слов без
  легального разрыва. Контурный перенос (`hyphenate_long_words_with_breaks`) и обтекание
  баллона (`knuth_plass_bubble_wrap`) получают дефис `-` и перенос строки автоматически.

## Тесты

```
cargo test -p photocraft-engine --lib snow_        # 46 passed
cargo test -p photocraft-engine --lib snow_hyphenation  # 8 passed
```

Покрыто: детекция fr/en/de/es/tr, кириллица ru/uk, CJK → None, слоги «НЕОБХОДИМОСТЬ»,
«extraordinary», короткие слова не режутся, апострофы, байтовые границы,
`language_hyphenation_breaks_words_with_a_hyphen` (дефис + перенос строки при узком баллоне).

## Ручная проверка в GUI

1. `cargo run -p photocraft` (или `D:\Photoncraft\release\photocraft.exe`).
2. Создать документ, овальным выделением (Magic Wand / Ellipse Marquee) выделить узкий
   вертикальный баллон.
3. TypeR → вставить «НЕОБХОДИМОСТЬ» (или «EXTRAORDINARY ADVENTURE»), стиль с кеглем 26–36 pt.
4. Ожидаемо: слово переносится по слогам с дефисом (`НЕОБ-ХО-ДИ-МОСТЬ`), не вылезает за
   баллон и не сжимается; английское слово — по правилам en.

## Ограничения

- Библиотека TeX-паттернов (`vendor/hyphen/*Patterns.js`) не портирована: переносы строятся по
  правилам слогов TypeR, как и требовалось в постановке. При необходимости паттерны можно
  добавить отдельной таблицей на язык.
- Визуальная проверка фазы выполнена через контурный перенос и unit-тесты; ручной прогон в GUI
  остаётся за пользователем (сценарий выше).
