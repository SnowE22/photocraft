# Фаза 2: интерактивный редактор переносов (Line Breaks)

Дата: 2026-11-05. Ветка: `community/gpu-screentone-preview`.

## Что сделано

- Новый модуль `crates/ui-egui/src/snow_breaks_ui.rs` (префикс `snow_`):
  - `line_break_points(line)` — точки переноса по всем буквенным словам строки через
    `photocraft_engine::snow_hyphenation` (индексы символов внутри строки);
  - `split_line(line, char_index)` — делит строку, ставит дефис в конце левой части;
  - `merge_lines(left, right)` — склеивает обратно, снимая дефис (без лишнего пробела внутри
    слова; с пробелом — если дефиса не было);
  - `byte_at_char` — безопасное смещение в байтах;
  - `show(ui, line, next)` — полоса предпросмотра над редактором: при наведении на строку под
    словами появляются полупрозрачные маркеры `·` в допустимых точках переноса; клик по маркеру
    возвращает `BreakAction::Split`, клик по метке соединения в конце строки (строка уже
    оканчивается на `-`) — `BreakAction::Merge`.
- Интеграция в `snow_typesetter_ui.rs`:
  - над единым редактором сценария показывается строка предпросмотра текущей реплики
    (и следующей — для соединения);
  - `split_current_line_at(char_index)` правит `script_buffer` (дефис + перевод строки) и
    пересобирает очередь через `sync_state_from_script_buffer`; `merge_current_line()` делает
    обратное; курсор редактора после правки переводится на актуальную строку.
- Модуль зарегистрирован в `crates/ui-egui/src/lib.rs` (`pub mod snow_breaks_ui;`).

## Тесты

```
cargo test -p photocraft-ui-egui --lib snow_breaks       # 5 passed
cargo test -p photocraft-ui-egui --lib snow_typesetter   # 16 passed
```

Покрыто: точки переноса для русского и английского текста, пунктуация не создаёт переносов,
split→merge возвращает исходное слово, склейка без дефиса даёт пробел, байтовые смещения на
границах символов.

## Ручная проверка в GUI

1. Открыть TypeR с длинной репликой (например «НЕОБХОДИМОСТЬ пройти вперёд»).
2. Навести мышь на строку предпросмотра над редактором — между слогами появляются `·`.
3. Клик по маркеру — строка делится на две с дефисом (`НЕОБХ-` / `ОДИМОСТЬ …`), в редакторе
   появляется перевод строки.
4. Клик по метке соединения справа от строки, оканчивающейся на `-`, — строки склеиваются,
   дефис исчезает.

## Ограничения

- Переносы по-прежнему без TeX-паттернов (правила слогов из фазы 1).
- В рабочем дереве есть незакоммиченная работа другого агента (text shape candidates,
  auto-align, multi-bubble; ~3.4k строк в `snow_typesetter_ui.rs`, `snow_typesetter.rs`,
  `lib.rs`). Интеграция фазы 2 лежит поверх неё и потому не выделена в отдельный коммит:
  в Git закоммичен сам модуль `snow_breaks_ui.rs` и этот отчёт.
